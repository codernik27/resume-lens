# 🔍 ResumeLens — Intelligent ATS & Skill Gap Scanner

[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit_Web_App-6366f1?style=for-the-badge&logo=googlechrome&logoColor=white)](https://codernik27.github.io/resume-lens/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**ResumeLens** is an open-source, client-side ATS diagnostic engine designed to help job seekers, students, and engineers optimize their resumes against job descriptions to pass Automated Applicant Tracking Systems.

👉 **[Try the Live Web App Here](https://codernik27.github.io/resume-lens/)**

---

## ⚡ Problem It Solves
Over 75% of resumes are discarded by automated ATS systems before reaching human recruiters due to missing keyword density and terminology mismatch. ResumeLens solves this by:
- Tokenizing job descriptions against a curated technical ontology.
- Pinpointing exact missing hard/soft skills required by employers.
- Providing an instant **Match Score** and risk assessment.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, FontAwesome
- **NLP & Engine:** Client-side tokenization, set theory frequency matching
- **Deployment:** GitHub Pages (Serverless CI/CD)
